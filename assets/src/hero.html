One role brief in.
A full hiring
package out.

A Claude plugin of coordinated talent-acquisition agents. Tell it what you are hiring for. One research pass builds a per-role Context Pack from public data; nine document specialists write in parallel from the same pack; a critic challenges each draft, a deterministic renderer builds the documents, and a QA gate signs off the package.

Zero setup cost

Works with no connections. Public data plus a bundled baseline snapshot is the default path. Connectors are optional and read-only.

Every number cited

Sourced (named public source and date), Estimate (method shown), or Internal (your data). No receipt, no ship.

Ask small or large

"Write me a JD" runs one specialist. "Run Talent One" runs all nine in parallel. Both pass the same checks.

Updates in seconds

Documents never pass through a model at render time. A comp change re-renders the kit in about one second.
