# Candidate comms: the CO-STAR prompt (interview-coaching example)

Use CO-STAR whenever a human reads the output. The lazy version gets you platitudes; six
CO-STAR lines get you a prep plan you could hand a candidate today.

## The lazy version (don't)

```
Be my interview coach. Help me coach this candidate.
```

## The CO-STAR version (do)

```
Context: Senior backend engineer. Final round next Tuesday.
Strong on systems design. Weak on behavioral. Eight years at one
company, never done a panel loop.

Objective: A 90-minute prep plan they can run solo this weekend.

Style: Direct. Specific drills. No motivational filler.

Tone: Honest coach. Name the gaps without softening them.

Audience: Senior IC. Reads on a phone between meetings. Dislikes
corporate boilerplate.

Response: Five sections. Each one has a drill, a time estimate,
and what "ready" looks like.
```

## Blank template

```
Context: [who the candidate is, the situation, the real gaps]
Objective: [the single outcome you want]
Style: [format and level of specificity]
Tone: [how it should feel: honest, warm, clinical]
Audience: [who reads it and how they read]
Response: [exact output shape: sections, length, structure]
```

Use CO-STAR for candidate updates, hiring-manager debriefs, rejection notes and offer
framing. In the funnel workflow it is the frame for the hiring-manager message: number
first, the gap, the cost, the fix.
