A
For the agent

The slot contract

Templates ship already filled with a worked example, so they never look broken and an agent can see the intended shape and length of every field. Filling is a replace-in-place operation against data-slot attributes.

data-slot="role.title"
Replace this element's text only. Keep every attribute and every wrapper.
data-repeat="orgs"
Container. Duplicate or delete its first child as the row pattern. Row count is up to the agent. The range in data-count is guidance.
data-bar="0.62"
Geometry slot. Set the number and the matching inline width/left percentage on the same element.
data-optional
Delete the whole block if the search has no data for it. Never fill it with hedging prose.
data-cite="sourced|estimate"
Provenance. Every number in a talent artifact is one or the other, and the pill next to it must agree.
Hard rule

An agent may delete blocks and repeat rows. It may not invent new blocks, new colors, or new font sizes. If the data doesn't fit a pattern here, it goes in prose.

12 · Callouts
Three only. Insight (cheong) · Caution (dan) · Gate (jeok). Nothing else gets a colored border.
Insight

A non-obvious read the recruiter can repeat in a hiring-manager meeting.

Caution

A known way this search fails. Always paired with the countermeasure.

Gate

Binary. Eligibility, licensure, clearance. Word with counsel; ask in writing.
